# ARISE

## Description
- Arise is a 2d puzzle platformer game which is inspired by solo leveling arise command of the protagonist. The player is a stickman which can summon it's troop and solve the puzzle accordingly currently the levels are upto 15 and they are quite easy.

## Game Mechanics
- Arise(Command) which summons a troop, your mouse must be close to the ground to summon it
- Normal movement
- Troop deletion
- Spikes
- ObjectOnHold
- ObjectOnTrigger

## Goal

- To solve the puzzle and complete the level

## Control
- W A S D (Movement)
- Mouse Left Click(Arise Command)
- Mouse Right Click(Troop deletion)
- T (level restart)
- R(All troop deletion)
- ESC ( MENU BUTTON)

## Technology Stack
- Unity Engine(2D)
- C# (Scripting)
- ShaderLAb(2D)
- Cinemachine(Camera)
- Player Prefs (data Storage)
